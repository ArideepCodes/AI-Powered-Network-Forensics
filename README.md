# ✨ Overview

The **AI-Powered Network Packet Forensics Analyzer** is a production-ready cybersecurity and digital forensics platform designed to analyze network traffic, investigate PCAP files, detect malicious activities, and generate AI-assisted threat intelligence insights.

The platform combines:
- packet-level network analysis
- machine learning threat detection
- forensic investigation tools
- interactive visual analytics
- automated reporting

into a centralized cyber investigation dashboard.

Built using:
- Streamlit
- Scapy
- Scikit-learn
- Plotly
- Python

the system provides a practical environment for:
- threat hunting
- incident response
- network forensics
- cybersecurity education
- security auditing

# 🛡️ Threat Detection Categories

The AI/ML engine classifies packets into 5 categories:

| Threat Type | Description |
|---|---|
| ✅ Normal | Standard legitimate traffic |
| 🔍 Port Scan | Reconnaissance activity detection |
| 🚨 DoS Attack | Denial-of-Service traffic patterns |
| 🦠 Malware Traffic | Suspicious command & control behavior |
| ⚠️ Suspicious Anomaly | Unusual traffic anomalies |
